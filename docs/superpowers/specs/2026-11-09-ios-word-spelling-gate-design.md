# iOS 单词复习：拼写才算过 — 设计规格

**日期：** 2026-11-09  
**状态：** 已实现，待体验

---

## 1. 背景

iOS 练习里，单词的「记住了」大多来自自评。新词一打开就展示全文，底部是「忘了 / 模糊 / 记住了」。到期后的挖空是点一下出答案，再自己打分。选择题和听音会由程序判分，但只证明认得这个释义。拼写要到 `repetitions >= 3` 才和挖空交替出现，而且拼写页还给出首字母提示。

没有一道必须做对才能过的产出题，间隔照样被拉长。人可以不经回忆就点「记住了」。

本规格只改 iOS 复习的通过线。SM-2 公式不变。Mac / Safari 的学习页题型不变。

---

## 2. 通过线

单词要拉长间隔，必须拼出英文，由程序对照标准答案。

- 完全一致（忽略首尾空白和大小写）：`remembered`
- 答案至少 4 个字母且编辑距离为 1：`fuzzy`
- 其余、空输入、或点「不会」：`forgot`

判定沿用 `SpellCheck`。`fuzzy` 和 `forgot` 仍按现有规则写入 SM-2，并在当前位置之后第 3 张（不足则末尾）再出现，直到 `remembered`。本轮第一次评分才写入 SM-2 和连胜，与现在相同。

单词卡上不再出现「忘了 / 模糊 / 记住了」。

---

## 3. 队列与题型

`ReviewQueue` 定稿题型。`QuizBuilder` 不再把卡片改成 `choice` 或 `listen`，也不再为这两种题拼干扰项。

| 条目 | 题型 |
|---|---|
| 单词，`status == new` 且 `repetitions == 0` 且 `introducedAt == 0` | `intro`（只看一次） |
| 其余有释义的单词 | `spell` |
| 短语，无论新旧 | `cloze`（点开后自评） |
| 整句 | `recall`（点开后自评） |
| 长片段 | 不进队列 |

没有中文释义的单词不进队列，不计入每日目标和连胜所需的可复习数，也不用来补足每日目标。已有复习进度保留。

`choice`、`listen` 的界面分支从复习页删除。朗读仍用于新词第一面，以及拼写提交之后。

---

## 4. 新词第一面

`intro` 展示单词、音标、释义、例句，并朗读。底部只有「看过了」。

「看过了」：

- 写入 `introducedAt = now`，并更新条目 `updatedAt`。
- 不调用 `SM2.apply`。不改 `status`、`easeFactor`、`interval`、`repetitions`、`nextReviewAt`。不计入 `vocabReviewedToday`，不计入连胜。
- 不把该 id 放入本轮已评分集合。
- 在当前位置之后第 3 张插入一张同词的 `spell` 卡（不足则末尾），然后进入下一张。本轮拼写若是该词第一次评分，照常写入 SM-2。
- 可撤销。撤销恢复会话，并恢复「看过了」之前的词条（`introducedAt` 回到 0）。

中途退出后再打开：`introducedAt > 0` 且仍未评分的新词直接以 `spell` 进入队列，不再展示第一面。

已经在学、待复习或已掌握的词没有 `introducedAt` 也直接拼写，不为它们补一次「看过了」。

---

## 5. 拼写题

提交前页面只含：

- 中文释义（含词性，有则显示）
- 挖空例句。没有例句时不显示空的 `______`
- 输入框。关闭自动大写和自动改正
- 「不会」和「提交」。输入为空时「提交」不可用

提交前不显示单词、不显示首字母提示、不朗读。现有的 `SpellCheck.hint` 不再出现在这张卡上。

提交后显示对错、正确拼写，并朗读，然后是「继续」。交互与现在的拼写结果页相同。

---

## 6. 短语和整句

短语和整句不要求默写。

- 短语一律 `cloze`：先隐藏英文，点开后自评。新短语不再走 `intro`。
- 整句仍是 `recall`：先看中文，点开后自评。每天新整句最多 3 句，规则不变。

---

## 7. 没有释义的单词

拼写需要中文题干。释义由程序补，练习时不要求用户先写释义。

补全对象：`vocabItems` 里 `definitions` 为空的单词。已有释义的不覆盖。

每次 App 进入前台跑一轮，顺序固定：

1. **内置词库。** 读取扩展包内全部 `lexicon-*.json`，用 `StarterPack.parse` 的条目做大小写不敏感的 `en` 全词匹配。按 `StarterPack.lexicons` 的顺序查找（日常高频、四级、六级、考研、雅思、托福），同一本里取文件中的第一条。写入 `definitions`（单条中文）、`phonetic`、`pos` 和 `updatedAt`。不改复习进度。
2. **已同步的大模型。** 词库未命中且 `AIConfig.resolve` 成功时，请求一次。提示词要求只返回 JSON：`definition`（简体中文，必填）、`phonetic`、`pos`。`definition` 为空、或与英文单词相同，视为失败。成功则写入同样的字段，不改复习进度。
3. **仍没有释义。** 保持空白。这一轮不再对该词请求模型；下次进入前台可以再试。词库查找每次都可以做。

详情页在释义为空时提供一个释义输入框。保存只写入 `definitions` 和 `updatedAt`，不改复习进度。保存后该词按第 3 节进入拼写队列。这是查不到时的出口，不是收词的主路径。

词库列表里，释义为空的单词在状态处显示「待出题」。今日队列为空、同时存在待出题单词时，今日页说明还有词在等待释义，而不是只显示没有复习。

---

## 8. 数据

词条新增内容字段 `introducedAt`（毫秒）。缺省或 `0` 表示没看过第一面。它不是复习字段：合并时跟释义一样，随 `updatedAt` 较新的那一份走。

Mac 再次收藏或评分时用展开原对象的方式保存，因此会留下这个字段。Mac 不读它，学习页不改。

不增加快照 `version`。旧快照没有该字段时按 `0` 处理。

---

## 9. 不做

- 改 SM-2 公式，或把「差一个字母」从 `fuzzy` 改成 `forgot`
- 改 Mac / Safari 的题型和评分
- 短语、整句默写
- 分享收词的交互。分享进来的裸单词靠第 7 节补释义
- 多义项确认卡。词库或模型的第一条释义直接作为题干
- 为已在学的词补插「看过了」

---

## 10. 测试

- `ReviewQueue`：未看过的新词是 `intro`；`introducedAt > 0` 或已有复习进度的单词是 `spell`；短语一律 `cloze`；整句仍是 `recall`；无释义单词不在队列里，也不计入可复习数。
- `ReviewSession`：「看过了」插入 `spell` 且该 id 仍算未评分；拼写卡没有自评按钮；`forgot` / `fuzzy` 的重现规则不变。
- `LibraryMutator`：「看过了」只写 `introducedAt` 和 `updatedAt`；补释义写入中文、音标、词性，且不覆盖已有释义。
- 词库匹配：大小写不敏感的全词命中，顺序靠前的词库优先；对不上返回空。
- 模型结果解析：合法 JSON 取出释义；空释义、非 JSON、释义等于英文单词时为空。
- 既有 `SpellCheck` 用例保持通过。`QuizBuilder` 里 choice / listen / 挖空交替的用例改为上述题型规则，或随分支删除。
- 提交前：`swift test`，以及 iOS 模拟器能打开复习页。拼写页核对：无首字母、无自评三按钮、提交前不朗读。
